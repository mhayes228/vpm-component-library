VPM Events Component

One record per event. Before the event it renders as an invitation; once the end time passes and a recap is filled in, the same card becomes the recap — same URL, same anchor.

Preview data is inline. This page ships its data in a <script type="application/json" data-vpm-events-data> tag so it works from file:// with no server. In production, delete that tag and point data-events-url at events/events.json.
